## 1.1.5
- Отчёты #4 и #5 (Windows, китайский язык): `spawn def=<существо>` создавал пешку без здоровья, истории и других
  компонентов, и на ней падал код самой игры (и патчи других модов). Теперь существо создаётся как полноценная пешка
  через её вид; для трупов, упакованных вещей, эффектов и снарядов — понятная ошибка; `build-instant` принимает только
  постройки.

## 1.1.4
Исправления по итогам второго, более широкого обзора: что может пойти не так у игроков, безопасность, честная игра.
- Честная игра точнее следует правилам самой игры:
  - призывать, двигать и вооружать можно только пешек, которые в игре слушаются приказов (не берсерков, не мехов вне
    радиуса или контроля механитора);
  - `move` и `attack` требуют призванной пешки;
  - гизмо наведения и выбор цели на карте мира проверяют правила самой игры;
  - приказы можно отдавать только своим караванам;
  - `equip` учитывает биокодирование, ограничения ролей и части тела, а `drop` — закреплённую одежду;
  - зоны подчиняются правилам инструмента зон, а в зону выращивания можно посадить только доступное растение;
  - `designate` предлагает только то, что есть в меню архитектора;
  - `quest-accept` проверяет условия задания и принимающего;
  - `prisoner` предлагает только режимы из вкладки заключённого.
- Честная игра больше не раскрывает то, чего не видит игрок: невидимых пешек, пешек в контейнерах под туманом,
  скрытые задания и фракции, смерти вне поля зрения, врагов под туманом в подсчётах, журнал игры (инструмент режима
  разработчика). Скрытая вещь теперь отвечает так же, как отсутствующая.
- Надёжность:
  - глубокие дампы `def`/`obj` ограничены и больше не вешают игру;
  - шаблон в `wait` не может повесить основной поток;
  - аргументы вне диапазона или не числа дают понятную ошибку;
  - ошибка при тайм-ауте ждущей команды больше не останавливает очередь;
  - перехваты событий никогда не ломают код самой игры.
- Ошибки ввода агента, например неверные числа или имена перечислений, больше не отправляются как отчёты о сбоях.
- Сохранения:
  - `load` открывает только сохранения из меню загрузки, а не произвольные пути;
  - два сохранения с одним именем не перезапишут друг друга;
  - `main-menu` требует `confirm=true`, как и `quit`.
- Приватность и безопасность:
  - ничего не отправляется, пока игрок не ответил на запрос согласия;
  - файл подключения доступен только владельцу с момента создания;
  - второй экземпляр игры больше не удаляет файл подключения первого.
- Windows: MCP-сервер и `rwb.py` работают с нелатинским текстом и именами пользователей, а команда MCP в игре
  использует `python`. Смена порта в настройках применяется сразу. README: путь в Workshop, Windows, Cursor, .NET SDK
  для `eval`; связанные документы теперь входят в мод.

## 1.1.3
Исправления по итогам полного обзора кода.
- Безопасность: чтение через `obj` больше не вызывает методы без power-доступа (чтение `Verse.Root.Shutdown` могло
  закрыть игру). Выключение сервера закрывает открытые соединения и отбрасывает команды в очереди; «Отключить всех
  агентов» не включает выключенный сервер.
- Честная игра: приказы, `drop`, политики и контекстные меню работают только для своих пешек (врага можно было
  разоружить); `build` учитывает исследования и другие условия; в счета можно добавить только рецепт этого верстака,
  уже открытый исследованием; `pawn` скрывает болезни, которые игрок не видит. `research-set` теперь проверяет
  предварительные исследования во всех режимах.
- Python-клиент: команда больше не отправляется дважды после обрыва соединения или тайм-аута; клиент ждёт столько же,
  сколько команда; пути с `&` больше не ломают `eval`. MCP-сервер отвечает на неверный запрос ошибкой, а не завершается.
- Игровые команды в главном меню отвечают «no game loaded», а не отчётом о сбое NullReferenceException.
- `newgame` и `page-next` больше не обрываются через 75 секунд. Второй `tick` во время первого отклоняется, а не
  останавливает оба. `batch` отклоняет ждущие команды до их запуска.
- Телеметрия: данные неудачной отправки сохраняются до следующей. Приёмник (telemetry/worker.js): временная ошибка
  GitHub больше не теряет автоматический issue, а дубликаты от одновременных отчётов стали гораздо менее вероятны.

## 1.1.2
- Отчёты #2 и #3 (Windows, китайский язык): агент, исследуя внутренности игры через `obj`, записывал свойство только
  для чтения и обращался к индексу за концом списка. Теперь `obj` пишет такие авто-свойства через их скрытое поле,
  понятно объясняет вычисляемые свойства и выход за границы и не падает на неоднозначных именах.
- Ошибки, вызванные вводом агента в `obj`, `exec`/`eval` и командах других модов, возвращаются агенту и больше не
  отправляются как отчёты о сбоях Agent Bridge.
- Защита: неверный или отрицательный `Content-Length` закрывает соединение, а не завершает игру; вложенность JSON
  ограничена 128 уровнями; не более 32 одновременных соединений; любая ошибка соединения изолирована.
- Честная игра: окна разработчика нельзя использовать через `window`.
- Быстрее поиск вещей: один индекс ThingID на кадр вместо перебора всех вещей на каждый запрос.

## 1.1.0 — честная игра: ИИ проходит всю игру
- **Режим честной игры** (настройка или команда `fair-play`, выключить может только игрок): без читов, рефлексии и
  опций режима разработчика, без вещей под туманом войны, скорость не выше 3.
- **Новая колония через настоящие страницы меню**: `newgame` или по шагам `newgame-open`, `page`, `page-set`,
  `page-next` (сценарий, рассказчик, мир, идеология, место высадки, колонисты).
- **Торговля** через окно торговли игры: `trade`, `trade-set`, `trade-accept`, `trade-cancel`.
- **Караваны и карта мира**: `caravan-form`, `caravans`, `caravan-move`, `world-objects`, `world-tile`,
  `world-menu`, `world-menu-choose`, `world-target`, гизмо каравана (`id=caravan:<ID>`).
- **Управление колонией**: `policies`, `assign` (одежда, еда, наркотики, медпомощь, разрешённая область),
  `area-edit`, `storage`, `prisoner`, `colony`, `research-set`.
- `menu`/`menu-choose` принимают `target=<id>` (торговцы и животные движутся); `tick` сразу сообщает `blocked-by-window`.
- **Агент-игрок** `Tools/rwb_agent.py`: Claude (официальный SDK) или любая OpenAI-совместимая/локальная модель играет
  честно; MCP-промпт `play_rimworld`. Тесты: `rwb_playtest.py` (24 проверки), `tests/test_agent_loop.py`.

## 0.4.0 — первый публичный репозиторий
- Отдельный мод (раньше был внутренним инструментом проекта Zero Sun); лицензия MIT.
- Собственный HTTP-сервер на TcpListener (keep-alive, на Windows не нужен URL ACL) и JSON без зависимостей.
- Harmony необязателен: ядро работает через MonoBehaviour, а Harmony добавляет наведение на клетку, точные тики и
  перехват событий.
- Реестр команд с уровнями доступа (Read/Act/Dev/Power), которые ограничивают настройки мода; API расширения для других модов.
- Настройки мода: включение сервера, порт, режим «только чтение», разрешения, список агентов, последние команды,
  команда MCP, индикатор на экране.
- Анонимная статистика и отчёты об ошибках (можно выключить, вопрос при первом запуске, сервер сбора пока не задан);
  кнопка отчёта об ошибке на GitHub.
- Переводы на все 29 языков игры.
- Экономный вывод: без полей null/false, округлённые числа, проекция `fields`, команда `snapshot`.
