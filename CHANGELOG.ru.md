# История изменений

[English](CHANGELOG.md) · **Русский**

## 1.0.0 — первый выпуск в Steam Workshop
- Обложка и скриншоты для Мастерской; анонимная статистика уходит на Cloudflare-сервер проекта
  (статус в настройках: доставлено / отложено / нет связи), новые сигнатуры ошибок становятся issue на GitHub.
- Новая команда `telemetry`; в окне настроек версия показывается один раз (у окна уже есть заголовок).
- Индикатор агента перенесён ниже верхней панели и увеличен; `attack`/`move` сообщают, если пешка без сознания или мертва.
- `rwb eval` подключает LudeonTK; скрипт чистой папки релиза (`Tools/make_release.py`).

## 0.4.0 — первый публичный репозиторий
- Отдельный мод (раньше был внутренним инструментом проекта Zero Sun); лицензия MIT.
- Собственный HTTP-сервер на TcpListener (keep-alive, на Windows не нужен URL ACL) и JSON без зависимостей.
- Harmony необязателен: ядро работает через MonoBehaviour, а Harmony добавляет наведение на клетку, точные тики и
  перехват событий.
- Реестр команд с уровнями доступа (Read/Act/Dev/Power), которые ограничивают настройки мода; API расширения для других модов.
- Настройки мода: включение сервера, порт, режим «только чтение», разрешения, список агентов, последние команды,
  команда MCP, индикатор на экране.
- Анонимная статистика и отчёты об ошибках (можно выключить, вопрос при первом запуске, сервер сбора пока не задан);
  кнопка отчёта об ошибке на GitHub.
- Переводы на все 29 языков игры.
- Экономный вывод: без полей null/false, округлённые числа, проекция `fields`, команда `snapshot`.

## 0.3.0 (внутренняя)
- Проверено вживую на RimWorld 1.7 (Waylith/Linux): дескриптор в домашней папке, сохранение и загрузка с учётом
  RimSaves, точная остановка тиков, распознавание окон-пауз, ключи гизмо без привязки к языку, ручные приоритеты работ.
