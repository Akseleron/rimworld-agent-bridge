# ИИ играет в RimWorld — честно

[English](PLAYING.md) · **Русский**

Agent Bridge — инструмент для агентов и моддеров, а ещё игрушка. Включите **честную игру**, и любой ИИ сможет вести
вашу колонию ровно с теми возможностями, что есть у игрока: без читов и подглядывания. Смотрите со стороны и в любой
момент берите управление на себя.

## Честная игра

Настройки → Настройки модов → Agent Bridge → **Честная игра (только то, что может игрок)**. Агент может включить её
сам командой `fair-play`, а выключить — только вы. Пока режим включён:

- **запрещено:** спавн, урон и лечение, инциденты, погода, режим бога, debug-действия, C#-eval, рефлексия (`obj`,
  `patches`, `debug-list`), пункты меню и гизмо режима разработчика («Dev: …»), максимальная скорость;
- **скрыто:** всё под туманом войны и внутренности инцидентов (видны только письма и сообщения);
- **разрешено:** всё, что делает игрок:
  - приказы, меню правого клика, гизмо и способности;
  - строительство, зоны и области, склады;
  - работы, расписания, политики, исследования, пленники;
  - торговля, караваны и карта мира;
  - диалоги и письма, сохранение и загрузка;
  - новая колония через обычные страницы настройки.

Время идёт только когда агент вызывает `tick`, поэтому он может думать сколько угодно, и колония от этого не страдает.

## Кто будет играть

| Игрок | Как подключить |
|---|---|
| Claude Code / Codex / Cursor / любой MCP-клиент | добавьте MCP-сервер (Настройки мода → «Скопировать команду настройки MCP») и используйте промпт `play_rimworld` или напишите «поиграй в мою колонию RimWorld честно» |
| Claude через API | `pip install anthropic`, задайте `ANTHROPIC_API_KEY`, `python Tools/rwb_agent.py --provider claude` |
| Локальная модель (Ollama, LM Studio, llama.cpp, vLLM) | `python Tools/rwb_agent.py --base-url http://localhost:11434/v1 --model qwen3:32b` |
| Любой OpenAI-совместимый сервис | `--base-url <адрес>/v1 --model <имя> --api-key <ключ>` |

Параметры `rwb_agent.py`:
- `--newgame` — сначала начать колонию из главного меню;
- `--goal "…"` — цель для агента;
- `--steps 200` — сколько команд агент может отправить;
- `--effort high` — глубина размышлений (только для Claude);
- `--log play.jsonl` — полная запись всех решений и команд.

Скрипт сам включает честную игру, играет и ставит игру на паузу, когда останавливается. Прервать можно в любой момент через Ctrl+C.

Совет: лучше всего играют модели с хорошим вызовом инструментов и большим контекстом. Маленькие локальные модели
тоже работают, но забывают планы: давайте им узкую цель («пережить первые 10 дней», «построить кухню и
морозильник»). Системный промпт агентов лежит в `Tools/rwb_play_prompt.md`, его можно править под свой стиль игры.

## Проверка, что агент-игрок справляется

- `python Tools/rwb_playtest.py --days 1` — 24 проверки. Из главного меню: новая колония через страницы настройки и
  включение честной игры. Затем отказ на читы, работы, расписания, политики, области, зоны, склады, исследования,
  строительство, приказы, день игры и караван.
- `python Tools/tests/test_agent_loop.py` — цикл агента со сценарной «моделью» против запущенной игры.
- `python Tools/rwb_smoke.py` — все ~90 команд-инструментов (режим разработчика, честная игра выключена) на
  одноразовой колонии.

## Команды для игры

| Область | Команды |
|---|---|
| Обзор | `snapshot`, `colony`, `alerts`, `letters`, `windows`, `area`, `pawns`, `pawn`, `things`, `cell` |
| Время | `tick n=…` (останавливается на диалогах: `stop=blocked-by-window`), `pause`, `speed`, `wait until=letter…` |
| Приказы | `draft`, `move`, `attack`, `equip`, `drop`, `forbid`, `job-end`, `gizmos`/`gizmo` + `target`, `menu`/`menu-choose` (`target=<id>` для движущихся целей) |
| Колония | `build`, `designate`, `zone`, `area-edit`, `storage`, `bills`, `work`, `schedule`, `assign`, `policies`, `research`/`research-set`, `prisoner` |
| Диалоги | `dialog`, `window`, `letter` |
| Торговля | открыть через `menu-choose` («Торговать с …») или пульт связи, затем `trade`, `trade-set`, `trade-accept`, `trade-cancel` |
| Мир | `caravan-form` (нужен `tile`), `caravans`, `caravan-move`, `world-objects`, `world-tile`, `world-menu`/`world-menu-choose`, `world-target`, гизмо каравана через `gizmos id=caravan:<ID>` |
| Новая игра | `newgame` (все страницы сразу) или `newgame-open`, `page`, `page-set`, `page-next` |
| Сохранения | `save` (никогда не перезаписывает), `load`, `saves` |
