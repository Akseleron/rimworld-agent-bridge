# Протокол (rwb-1)

[English](PROTOCOL.md) · **Русский**

- **Транспорт:** HTTP/1.1 на `127.0.0.1:<порт>`. По умолчанию 8765; если занят, берётся следующий свободный, до +9.
  Keep-alive поддерживается.
- **Обнаружение:** JSON-дескриптор `{protocol, version, port, token, pid, gameRoot, managed, runtime, os, assemblies}`.
  Лежит в `~/.local/state/rimworld-agent-bridge/descriptor.json` или `%LOCALAPPDATA%\AgentBridge\descriptor.json`
  (переопределяется через `RWB_DESCRIPTOR`). Перезаписывается при каждом запуске и удаляется при остановке сервера.
- **Авторизация:** заголовок `X-Token: <token>` (или `Authorization: Bearer <token>`). `GET /health` работает без токена.
- **Идентификация:** необязательный заголовок `X-Agent: <имя>` показывается в настройках мода (например `claude-code`,
  `codex`, `mcp:cursor`).
- **Запрос:** `POST /` с JSON-объектом `{"cmd": "<имя>", ...аргументы}`.
- **Ответ:** `{"ok":true,"result":…}` или `{"ok":false,"error":"…"}`. HTTP 401 — неверный токен, 504 — главный поток
  игры не ответил.

## Соглашения

- Вещи — строки `ThingID` (`Human123`, `Steel4567`). Клетки — аргументы `x`,`z`; позиции в ответах — `[x,z]`.
- Defs — по `defName`. Гизмо — по `key` (`key:Command_ColonistDraft`, `verb:Gun_Revolver`, `ability:<def>`), не по подписи.
- В ответах опускаются поля `null` и `false`; булевы поля появляются, только когда равны true.
- `fields:["a","b"]` оставляет только эти ключи у объекта верхнего уровня или у каждого элемента списка верхнего уровня.
- `timeout` (секунды, по умолчанию 60, максимум 900) — срок ожидающих команд (`tick`, `wait`, `load`, `save`, …).
- Команды выполняются в главном потоке игры, один кадр на запрос (несколько лёгких делят кадр).
  Во время загрузки работают только `state help feed wait perf mods patches windows capabilities`, остальные ждут.

## Уровни доступа

| Уровень | Примеры | Условие |
|---|---|---|
| Read | snapshot, pawns, feed, wait, obj get | всегда |
| Act | draft, move, gizmo, designate, save, load | выключено в режиме «только чтение» |
| Dev | spawn, incident, damage, debug, quicktest | «разрешить dev-команды» + режим разработчика (если требуется) |
| Power | exec/eval, obj set/call | «разрешить мощные команды» + режим разработчика (если требуется) |

## События

`feed after=<seq>` возвращает строки лога, сообщения, письма, инциденты и смерти с растущим `seq`.
`wait until=letter pattern=Raid after=<seq>` блокирует, пока не придёт подходящее событие. Передавайте последний
увиденный `last`, чтобы ничего не пропустить. Без Harmony перехватываются только строки лога и письма (опросом).

## Eval

`rwb.py eval '<C#>'` компилирует сниппет против сборок запущенной игры (берёт их из дескриптора) через `dotnet` и
передаёт путь к DLL команде `exec`. Одиночное выражение возвращается как результат; для операторов нужен `return`.
`args` имеет тип `Dictionary<string, object>`. Если вернуть `AgentBridge.Pending`, команда будет ждать несколько кадров.
