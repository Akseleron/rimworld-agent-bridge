# Приватность

[English](PRIVACY.md) · **Русский**

Agent Bridge принимает подключения только с `127.0.0.1` (ваш компьютер) и требует случайный токен. Управлять игрой могут
агенты на вашей машине; из сети к ней не подключиться.

## Анонимная статистика и отчёты об ошибках

Обе функции **включены по умолчанию**. При первом запуске мод один раз спрашивает согласие, выключить их можно в любой
момент в *Настройки → Настройки модов → Agent Bridge*. Кнопка «Показать, что будет отправлено» выводит точное содержимое.

**Собирается:**

- случайный ID установки (создаётся локально, не связан со Steam или с вами);
- версия Agent Bridge, версия RimWorld, среда выполнения (coreclr/mono), семейство ОС (Unix/Win32NT), язык игры;
- длительность сессии в минутах, установлен ли Harmony;
- счётчики успехов и ошибок по командам (только имена зарегистрированных команд);
- *типы* подключившихся агентов (claude, codex, mcp, curl, other) — никогда не исходная строка клиента;
- для сбоев Agent Bridge: тип исключения, имя команды, хеш-сигнатура и до 12 кадров стека. Домашняя папка, имя
  пользователя и абсолютные пути вырезаются.

**Не собирается никогда:** имена пешек, колоний и сохранений, пути к файлам, ваше имя пользователя, списки модов,
содержимое игры, местоположение по IP (сервер-получатель не хранит IP).

**Куда уходят данные:** адрес сервера задаётся в `Telemetry.DefaultEndpoint`. **В этой сборке он пустой**, поэтому
ничего не отправляется. Эталонный получатель (`telemetry/worker.js`) суммирует счётчики и заводит в этом репозитории
issue на каждую новую сигнатуру ошибки, без дублей.

Кнопка «Сообщить об ошибке» сама ничего не отправляет: она открывает в браузере заполненный issue на GitHub и копирует
полный отчёт в буфер обмена, чтобы вы проверили его перед публикацией.
